Cooklang is an open, plain-text markup language for recipes. Recipes are files you own: readable without any app, easy to keep in git, and simple to turn into shopping lists, meal plans and reports.

**Start here**
- [Write your first recipe](https://cooklang.org/docs/getting-started/)
- [Playground](https://cooklang.github.io/cooklang-rs/): try the syntax in your browser
- [Language spec](https://cooklang.org/docs/spec/)
- [Manifesto](https://github.com/cooklang/.github/blob/main/MANIFESTO.md)

**Tools**
- [CookCLI](https://github.com/cooklang/cookcli): shopping lists, a recipe web server and reports from the command line
- [Editor support](https://github.com/cooklang/awesome-cooklang#desktop--editors): VS Code, Obsidian, Emacs, Sublime Text, Kakoune, any LSP editor
- [Cook apps](https://cooklang.org/app/) for iOS and Android, and [Cook Cloud](https://cook.md/) to sync your recipe folder across phone, desktop and CLI
- [Awesome Cooklang](https://github.com/cooklang/awesome-cooklang): projects and libraries that work with Cooklang

**Get involved**
- [Discord](https://discord.gg/fUVVvUzEEK) and [r/cooklang](https://www.reddit.com/r/cooklang/): ask for help or say hello
- [Spec discussions](https://github.com/cooklang/spec/discussions): suggest ideas for the language
- [Current development](https://github.com/orgs/cooklang/projects): vote with 👍 or contribute
- [Help needed](https://github.com/cooklang/fine_tune): validate recipes to improve AI conversion
